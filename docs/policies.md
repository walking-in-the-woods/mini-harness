# Политики доступа к файлам

Правится в `config.yaml`, секция `fs`. Правки подхватываются при
новом запуске REPL.

## Три списка

```yaml
fs:
  whitelist:
    - "**"

  blacklist:
    - "**/.git/**"
    - "**/*.key"

  writable:
    - "output/**"
    - "notes/**"
    - "*.md"
    - "*.txt"
```

- **`whitelist`** — что модель может видеть вообще. Если файл не
  матчится ни одним шаблоном, доступа нет (read и write).
  **Пустой список означает «ничего не разрешено».** Отсутствие ключа
  даёт дефолт `["**"]`.
- **`blacklist`** — что запрещено, даже если прошло whitelist.
  Применяется после whitelist. Пустой список = ничего не запрещено.
- **`writable`** — что модель может предлагать к записи. Пустой
  список = запись везде запрещена. На чтение не влияет.

## Glob-синтаксис

| Шаблон | Матчит |
|---|---|
| `*` | один сегмент, кроме `/` |
| `**` | любое число сегментов, включая ноль |
| `?` | один символ, кроме `/` |
| `docs/**` | всё внутри `docs/`, но не сам `docs` |
| `**/*.md` | любой `.md` на любой глубине |
| `*.md` | только `.md` в корне `workspace/` |

## Расширения на запись

Помимо списков, работает `WRITE_EXT_BLOCK` в `harness/fs_guard.py`:

- `.sh`, `.bash`, `.zsh`, `.fish`, `.ksh`
- `.exe`, `.bat`, `.cmd`, `.ps1`, `.vbs`
- `.py`, `.js`, `.ts`, `.rb`, `.go`, `.rs`, `.lua`
- `.php`, `.jsp`, `.cgi`, `.pl`
- `.whl`, `.egg`

Модель может **читать** любые из них. Запись блокируется независимо
от `writable`. Если нужно передать пользователю скрипт — модель
сохранит его как `.txt`.

## Подводные камни

- **`workspace/` не должен быть симлинком на `$HOME`.** Guard
  развернёт symlink и откажет, но лучше не проверять.
- **Уже существующие файлы.** Guard проверяет только то, что модель
  **предлагает записать** — за чистоту уже лежащих в workspace
  файлов отвечает пользователь.
- **Проверка на чтение не зависит от существования файла.**
  `check_read` возвращает `True` для несуществующего файла, если
  путь разрешён. Отсутствие файла обнаруживает tool.

## Как расширить

**Добавить разрешение на запись в новую папку:**

```yaml
writable:
  - "output/**"
  - "notes/**"
  - "drafts/**"       # ← добавили
  - "*.md"
```

**Убрать `Makefile` из чёрного списка:**

```yaml
blacklist:
  - "**/.git/**"
  # - "**/Makefile"     # закомментировано
```

**Разрешить только конкретный подкаталог:**

```yaml
whitelist:
  - "input/**"
  - "output/**"
```

После правки — новый REPL. Перезапуск контейнера (которого нет)
не нужен.
