# Mini Harness

Локальный ассистент с tool-calling, работающий одним Python-процессом
без контейнеров. Предназначен для слабых машин: 8 ГБ RAM, ~1.5 ГБ
свободно. Модель инференса — отдельно установленный сервер на той же
машине.

## Для кого

- Разработчикам, которым нужно обработать документы или код локальной
  моделью, не отдавая данные наружу.
- Пользователям слабых машин, для которых Docker-стек не влезает
  в память.
- Тем, кому нужен предсказуемый tool-calling агент без скрытых
  сетевых вызовов.

## Что решает

- **Ограничение файловой системы.** Чтение и запись — только внутри
  `./workspace`, с белым и чёрным списками, защитой от symlink
  escape и NFKC-гомоглифов.
- **Ручное подтверждение записи.** Одна запись на сессию, пользователь
  видит diff и вводит одноразовый код.
- **Защита от самоинъекции.** Файл, записанный в текущей сессии,
  нельзя прочитать в той же сессии.
- **Нейтрализация инъекций.** Все tool-результаты экранируются перед
  отправкой в контекст.
- **Единственный сетевой канал.** Внешние API — только через явный
  whitelist маршрутов.

## Чего не делает

- Не изолирует процесс инференса от сети.
- Не обеспечивает аутентификацию клиентов — один пользователь на
  машине.
- Не защищает от пользователя, который сам вводит код подтверждения,
  не читая diff.

Подробнее — [Модель угроз](security-model.md).
