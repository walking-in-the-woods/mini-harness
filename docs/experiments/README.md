# Эксперименты

Практические проверки возможностей моделей на конкретном железе.
Здесь фиксируются результаты прогонов guided mode и чата — что
работает, что нет, где начинаются границы.

## Список экспериментов

| Файл | Тема | Дата |
|---|---|---|
| [micro-models-n100.md](micro-models-n100.md) | Микромодели 3B на N100/8GB в guided mode | 2026-09 |

## Зачем это

Документация в `docs/` описывает, *как устроен* harness. Здесь — *что
он даёт на практике* с конкретными моделями. Числа и результаты
прогонов, а не архитектурные решения.

Каждый эксперимент — это лог одного или нескольких запусков с
одинаковой методологией:

1. Тестовые данные (`input/...`).
2. Prompt-файл (`input/prompts/...`).
3. Команда запуска.
4. Полный вывод stderr и stdout.
5. Проверки результата (`py_compile`, `grep`, функциональные тесты).
6. Выводы о границах модели.

## Как дополнять

Новые эксперименты — отдельными блоками в существующих файлах, если
тема та же. Отдельным файлом — если меняется железо, семейство
моделей или режим (guided vs autonomous).

Шапка каждого файла:

```md
## Контекст
- Машина: ...
- Модель: ...
- Режим: ...
- num_ctx / num_predict: ...
- Дата: ...
```

Это позволяет сравнивать прогоны между собой и понимать, менялось
ли что-то кроме модели.

## Что уже установлено

Сводка по микромоделям 3B на N100 (подробности — в
[micro-models-n100.md](micro-models-n100.md)):

| Задача | Модель | Результат |
|---|---|---|
| Суммаризация статьи | llama3.2:3b | 3 из 4 требований |
| Извлечение 5 фактов списком | llama3.2:3b | 5 из 5 |
| Добавление методов в класс | qwen2.5-coder:3b | идеально |
| Docstrings с условными блоками | qwen2.5-coder:3b | идеально |

**Границы:**

- **Структурные задачи** (список, docstring, метод) — 3B справляется,
  включая простые условные правила.
- **Содержательные задачи** (суммаризация с 4+ требованиями) —
  предел: 3 требования.
- **Специализация модели важна.** `llama3.2:3b` — текст,
  `qwen2.5-coder:3b` — код. Обе на чужой территории — нет.
- **Reasoning-leakage у `qwen3:4b`** — известное ограничение этой
  сборки в Ollama, не применимо к `llama3.2` и `qwen2.5`.
